Duration

The duration of an interval (or temporal sequence) can have many different descriptions. An interval can be 1 day 2 hours, or 26 hours, or 1560 minutes, and so on. It is useful to be able to talk about these descriptions in a convenient way as independent objects, and to talk about their equivalences. The extent of an interval can be given using multiple duration descriptions or individual durations (e.g., 2 days, 48 hours), but these must all describe the same amount of time.

Five classes support the description of the duration of an entity ().

:TemporalDuration
the common super-class
:Duration
has properties to describe the duration using a scaled number (i.e., a temporal quantity)
:GeneralDurationDescription
has a set of properties to specify a duration using calendar and clock elements, the definitions of which are given in the associated TRS description
:DurationDescription
is a subclass of :GeneralDurationDescription with the temporal reference system fixed to the Gregorian calendar
:TemporalUnit
is the class of standard durations that are used to scale a length of time, and to capture its granularity or precision

Note that :GeneralDateTimeDescription or :DateTimeDescription have different sets of properties to :GeneralDurationDescription or :DurationDescription. For example, :year (in :DateTimeDescription) has a range of xsd:gYear which is a position in the Gregorian calendar, while :years (in :DurationDescription) has a range of xsd:decimal so that you can say "duration of 2.5 years".
