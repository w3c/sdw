IANA Considerations

The link relation types below have been registered by IANA per Section 6.2.1 of [[RFC8288]]:

after Link Relation Type

Relation name
after
Description
refers to a resource associated with a time that ends before the time associated with the context resource
Reference
W3C OWL-Time recommendation,

before Link Relation Type

Relation name
before
Description
refers to a resource associated with a time that begins after the time associated with the context resource
Reference
W3C OWL-Time recommendation,

hasBeginning Link Relation Type

Relation name
hasBeginning
Description
refers to a resource associated with a time instant that is at the beginning of the time associated with the context resource
Reference
W3C OWL-Time recommendation,

hasEnd Link Relation Type

Relation name
hasBeginning
Description
refers to a resource associated with a time instant that is at the end of the time associated with the context resource
Reference
W3C OWL-Time recommendation,
