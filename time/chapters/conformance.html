Data conforms to OWL-Time if:

  • Temporal aspects are expressed as RDF
  • Temporal elements are organized around OWL-Time's temporal entities, instants and intervals
  • Relationships between temporal entities are defined using OWL-Time's temporal relations

OWL-Time-compliant knowledge graphs MAY include additional class instances, object and data properties, and additional RDF data.

A test-suite for temporal-entities with positions given using xsd:dateTime, is provided in the test directory of the repository. A set of queries which compute the relationships between temporal entities using the [[SPARQL-QUERY]] `CONSTRUCT` or `INSERT` operations, is provided.
